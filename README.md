# Д КЛИМА СЕРВИЗ – статичен сайт

Сайтът е изработен само с HTML, CSS и JavaScript и е подходящ за GitHub Pages.

## Качване в GitHub Pages
1. Създай repository, например `d-klima-serviz`.
2. Качи всички файлове и папки от тази директория.
3. GitHub → Settings → Pages → Deploy from a branch → избери `main` и `/root`.
4. Запази настройките и изчакай публикуването.

## Галерия
Добави собствените снимки в `images/gallery/` и промени съответните блокове в `index.html`, например:
`<img src="images/gallery/object-01.jpg" alt="Монтаж на климатик">`

## Преди публикуване
- Добави реалния адрес, ако искаш да бъде показван.
- Замени placeholder-ите в галерията с реални снимки.
- При желание добави фирмено лого.
- При желание можем да добавим Google Maps, форма за запитване, Cookie/Privacy страници и SEO настройки.
